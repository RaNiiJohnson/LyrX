# Backend Lyr'X

Ce workspace réserve la frontière Convex commune aux futurs clients web et
mobile. `convex.json` fixe `convex/` comme répertoire de fonctions.

Le lot 1 n'ajoute aucun schéma, aucune fonction, aucune authentification et ne
contacte aucun déploiement Convex. Ces éléments commenceront seulement dans un
lot capable de les vérifier de bout en bout.
